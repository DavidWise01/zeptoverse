How far from Planck?

10⁻²¹ / (1.616255×10⁻³⁵) ≈ 6.19×10¹³

One zeptometer is about 61.9 trillion Planck lengths. The project uses the recursive geometry 60/20/3/3/1/1 as a modeling hypothesis, not as a demonstrated physical lattice.

This GitHub chapter uses a self-contained vector diagram. A separate companion HTML with the rendered JPG embedded as a data URI was generated with the experiment, but is not uploaded as a JPG asset to this repository.
